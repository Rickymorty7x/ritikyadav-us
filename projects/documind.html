DocuMind

A retrieval-augmented Q&A app that lets you chat with your PDFs, papers, and notes — local-first, with inline citations.

View on GitHub Live site

Tech stack

Python LangChain FAISS Sentence-Transformers OpenAI API Streamlit

What it does

Drop in any folder of PDFs and DocuMind turns them into a chat interface — ask natural questions, get answers grounded in the source material with page-level citations you can click through.

Highlights

  • Local by default. Embeddings and the FAISS index live on disk; no documents leave your machine unless you opt in.
  • Source-cited answers. Every claim links back to the exact chunk it came from, so you can verify in one click.
  • Pluggable models. Swap between OpenAI, a local Ollama model, or a small fine-tuned encoder without touching the UI.
  • Hybrid retrieval. Dense + BM25 with a small cross-encoder reranker for the top 20 hits.

How it works

PDFs are split into section-aware chunks, embedded with all-MiniLM-L6-v2, and indexed in FAISS. At query time DocuMind retrieves the top-k passages, reranks them with a small cross-encoder, then feeds the survivors into the LLM with a tight citation-anchored prompt.
