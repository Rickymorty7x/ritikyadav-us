DreamFrame

A text-to-image playground for prompt experimentation — Stable Diffusion + ControlNet + a tiny library of reusable presets.

View on GitHub Live playground

Tech stack

Diffusers PyTorch Stable Diffusion ControlNet LoRA Gradio CUDA

What it does

DreamFrame is the place I run prompt-engineering experiments without re-writing boilerplate every time. Drop in a base image for a ControlNet pose / canny / depth pass, mix a LoRA, save the result as a named preset, and rerun it tomorrow.

Highlights

  • Preset library. Save the entire generation config (prompt, negative, sampler, scheduler, CFG, ControlNet, LoRAs) as a single JSON preset.
  • Side-by-side compare. Run the same prompt across two presets and view results in a synced gallery.
  • Lightweight UI. Gradio for the controls, custom CSS for a calmer look than the default.
  • Reproducible. Every output bundles its full config + seed alongside the image.

How it works

A thin wrapper over diffusers exposes a uniform generate(preset, prompt) interface. ControlNet preprocessors run on CPU; the diffusion pipeline runs on a single CUDA device. Outputs are written with embedded metadata so any generation can be replayed exactly.
