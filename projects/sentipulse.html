SentiPulse

A real-time sentiment dashboard for tweets and product reviews — fine-tuned DistilBERT under the hood, Plotly on top.

View on GitHub Live dashboard

Tech stack

Hugging Face Transformers DistilBERT PyTorch FastAPI Plotly SQLite Tweepy / RSS

What it does

Point SentiPulse at a hashtag, brand, or product. It pulls in a stream of recent posts, classifies them as positive / neutral / negative, and plots sentiment over time alongside a top-mentions feed.

Highlights

  • Fine-tuned DistilBERT on a mix of SST-2 + a small in-domain set of product reviews — small, fast, surprisingly resilient.
  • Streaming-friendly. Inputs flow through a FastAPI endpoint with batching; the dashboard updates without a page refresh.
  • Honest neutrals. Calibrated thresholds so the model doesn't pretend to be confident on borderline cases.
  • Drill-down view. Click a peak in the chart, see the actual messages that caused it.

How it works

A small ingestion worker collects messages and pushes them onto a queue; the inference service batches them, runs DistilBERT, and writes the result + raw text to SQLite. The dashboard reads from a time-bucketed view and re-renders the Plotly chart on a fixed cadence.
